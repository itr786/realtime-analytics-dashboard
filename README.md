# Realtime Analytics Dashboard

A portfolio dashboard demonstrating a Next.js interface backed by Django APIs and WebSockets for live KPI and event updates.

## Features

- Live KPI cards
- Event stream with reconnect handling
- REST-based historical metrics
- WebSocket subscription for current updates
- Responsive dashboard layout
- Lightweight browser-side state management

## Stack

Next.js · React · TypeScript · Django · WebSockets · PostgreSQL

The project uses generated/sample analytics data and is intended as a portfolio demonstration rather than a representation of proprietary production code.
